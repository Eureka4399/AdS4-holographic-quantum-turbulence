# Stationary reference profiles

The three included profiles have `nz=30` and parameter pairs `(mu, drive index)` of `(5, 3.8)`, `(6, 7)`, and `(8, 13.5)`.

The boundary flow parameter is `vy = -2*pi*drive_index/20`. Additional profiles, including the zero-flow profile used by the lattice script, can be obtained with `NewtonRaphson_vy` and the stationary-state notebook in `scripts/legacy/Statinary_state_with_v.m`.
